# Studio stabilization acceptance criteria

The Running Clubs golden investigation is the reference UI and regression workflow.

Studio must expose, from one investigation page:

- lifecycle and discovery confidence
- source diversity and observation count
- hypotheses and current/prior confidence
- directional evidence and provenance source
- Evidence Agent findings and recent agent runs
- Kernel commands and correlation identifiers
- confidence history
- event timeline
- investigation revisions

The Operations page must expose connector health and recent Kernel command history.

Every route must show an explicit loading state and actionable API error instead of silently rendering empty data.
