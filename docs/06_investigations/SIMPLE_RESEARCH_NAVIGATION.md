# Simple research navigation

The main path is Home → Investigation → next step. Home links directly to hypothesis setup when the latest investigation has no hypothesis; otherwise it opens the investigation overview. The overview gives one prominent next step based on existing hypothesis and reasoning data. These links use the existing routes and commands.

The workspace shows Overview, Evidence, Connections and Insights. Agents, History and Compare remain available under More views. The sidebar shows Home, Investigations and Discovery; operational tools remain under More tools. The cross-investigation map and system metrics are collapsed until requested.

The interface does not present fabricated investigations, source counts, activity or unavailable controls as real. A missing workspace response falls back to the investigation overview instead of assuming there is no hypothesis. Existing evidence, provenance, reasoning, history and graph capabilities remain accessible.
