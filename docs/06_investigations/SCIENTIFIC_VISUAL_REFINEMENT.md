# Scientific visual refinement

Home presents the latest investigation and one primary action before expandable operational detail. Source activity, agent activity and tools are available in disclosures. Decorative trend lines and the decorative orb have been removed so users do not mistake them for measured data.

The research workspace uses warm neutral surfaces, dark text and a restrained teal for primary actions and active navigation. Evidence and status accents retain distinct meanings: green for support, amber for caution, red for contradiction and violet for a separate reasoning context. The prominent text and action color pairs used in this pass exceed a 4.5:1 contrast ratio against their backgrounds.

The main navigation and scientific views continue to use the same routes and data contracts. The frontend production build verifies the layout code. A live browser review with connected investigation data remains useful after deployment.
