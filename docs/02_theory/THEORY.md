# Investigation-Centric Computing

YetSee treats a **Living Investigation** as the persistent computational artifact that accumulates evidence, knowledge, hypotheses, reasoning, decisions and outcomes over time.

The reference loop is:

`Observe -> Preserve -> Connect -> Investigate -> Reason -> Act -> Measure -> Learn`

The kernel does not prescribe a particular AI model, graph algorithm, ontology, detector or reasoner. These remain replaceable extensions around durable evidence and investigation history.
